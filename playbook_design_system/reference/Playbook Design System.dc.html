04 — FOUNDATIONS

Iconography

The signature of Playbook: icons are typographic glyphs set in Plex Mono, not drawn artwork. Geometric, monoline and instantly legible — a single family that scales with the type and never needs a sprite sheet.

06 — PRINCIPLES

Motion

Motion confirms, it never decorates. Transitions are short and eased; theme changes glide so the system feels like one continuous surface — try the toggle.

↻
Purposeful
Animate only state changes — a task completing, a panel opening, a theme flip.

160–280ms with ease-out. Long enough to read, short enough to stay out of the way.
